Before you start — quick checklist (any path)
1

Guided install

~5 minutes

Walk through 7 steps. Pick agents, name them, write personas, choose your slash-command vocabulary, opt into the optional skills and hooks you want. Best when you want to customize from scratch and learn the pieces as you go.

2

One-shot install with sample settings

~30 seconds — recommended for a test/empty repo first

Type a repo path. Click. Done. We pick sensible defaults: every agent, every optional skill, every hook, the maintenance doctrine, and a starter audit mission. Drops a complete self-maintaining fleet into your repo.

Best first run: a fresh, empty repo. Get familiar with the agents and how they work without affecting real code.

Safe to install in production repos too — the installer never overwrites your existing CLAUDE.md or settings.json (they save alongside as *.fleet for review). But for a real product repo, Path 1 (Guided) is preferred so you choose names, vocabulary, and only the agents/hooks you actually want.
3

Install fleet-generator as a project

~30 seconds — for power users

Workshop mode. Bundles a copy of fleet-generator.html into a workspace and ships agents that know how to edit it. Add features and customize defaults over time — every future project you generate from your fork inherits your additions. Includes a 3-mission tutorial ladder that teaches the file by editing it.
